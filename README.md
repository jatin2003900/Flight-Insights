# ✈️ Flight Operations Analytics Dashboard (Big Data Project)

## 📌 Overview
This project focuses on analyzing large-scale aviation data to extract actionable insights on flight performance, delays, and operational efficiency.  
It leverages Big Data technologies to process millions of records and presents insights through an interactive web dashboard.

---

## 🚀 Key Highlights
- Processed and analyzed 6M+ flight records using distributed data processing  
- Built an interactive dashboard for real-time exploration of flight operations  
- Identified key patterns in delays, cancellations, and route performance  
- Enabled user-driven analysis with dynamic filters (date, airport, routes)  

---

## 🛠 Tech Stack
- Data Processing: Apache Spark (PySpark)  
- Backend: Python  
- Frontend / Visualization: Streamlit  
- Visualization Libraries: PyDeck, Matplotlib  
- Data Source: US Flight On-Time Performance Dataset  

---

## 📊 Features

### 🔹 Flight Performance Analysis
- Monthly trends of flight volume and delays  
- Identification of high-delay routes and peak congestion periods  

### 🔹 Delay & Anomaly Detection
- Analysis of delay causes (weather, carrier, NAS, etc.)  
- Detection of routes with abnormal delay patterns  

### 🔹 Diversion & Route Insights
- Statistics on diverted flights and recovery patterns  
- Most frequent and longest routes visualization  

### 🔹 Interactive Dashboard
- Filter flights by date, airport, and route  
- Real-time metrics and visual insights  
- Map-based visualization of flight routes
